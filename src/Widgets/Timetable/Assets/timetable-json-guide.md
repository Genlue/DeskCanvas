# 课程表 JSON 格式 · 速查

「课程表」组件通过 JSON 文件导入数据，推荐流程：

1. 组件设置 →「**复制 AI 提示词**」
2. 把提示词与**课表照片**一起发给 AI（ChatGPT / DeepSeek / Claude 等）
3. 把 AI 返回的 JSON 保存为文件 → 组件设置 →「**导入 JSON 文件**」→ 在审核界面确认

> 下方标记之间的全部内容 = 「复制 AI 提示词」按钮复制的内容，同时也是完整的格式规范。
> 仓库根目录的 `sample-timetable.json` 是可直接导入的示例。

**字段速查**

| 字段 | 说明 |
| --- | --- |
| `name` | 课程名称（必填），照抄图片原文 |
| `teacher` / `room` | 教师 / 教室（看不清就省略） |
| `color` | 颜色 `#RRGGBB`（一般省略，组件自动配色） |
| `note` | 备注（可省略）：图片中该课程除课名/教师/教室外的补充信息，显示在悬停提示与审核清单 |
| `entries` | 上课时段（必填）：`day` 1–7（周一=1）、`periods` 节次数组（连堂合并如 `[1,2]`）、`weeks` 周次规则 |
| `weeks` | 省略=每周；`"1-16"` 区间、`"1-15单"` / `"2-16双"` 单双周、`"1,3,5"` 指定周 |
| `startDate` / `totalWeeks` / `periods` | 第 1 周周一 / 总周数 / 节次上下课时间表（均可省略） |

> JSON 没带节次时间也没关系：导入后可在组件设置「**节次时间**」里逐节手动填写（JSON 中带时间时会自动填入）。

导入时自动二次审核：错误（解析失败、无课程等）会阻止导入；警告（周次重叠、字段越界等）逐条列出供核对。
上限：文件 2 MB · 500 门课程 · 2000 个时段 · 30 节次。

## 字段规则
| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| `name` | 字符串 | **必填** | 课程名称。照抄图上文字：图上写「高数」就写「高数」，不要改写、简写或补全 |
| `teacher` | 字符串 | 选填 | 教师姓名；看不清就省略此字段 |
| `room` | 字符串 | 选填 | 教室 / 地点；看不清就省略此字段 |
| `color` | 字符串 | 选填 | `#RRGGBB`。**一般省略**（组件会自动分配配色）；仅当用户明确要求指定颜色时才填 |
| `note` | 字符串 | 选填 | 备注：该课程色块中除课名 / 教师 / 教室之外的补充文字（如「实验」「网课」「第 3 周起」），压缩为一句话（≤30 字）；没有就省略 |
| `entries` | 数组 | **必填** | 这门课的全部上课时段，至少 1 个 |
| `entries[].day` | 整数 | **必填** | 1=周一、2=周二、3=周三、4=周四、5=周五、6=周六、7=周日 |
| `entries[].periods` | 整数数组 | **必填** | 节次编号，从 1 开始；**连续节次必须合并进同一个数组** |
| `entries[].weeks` | 字符串 | 选填 | 周次规则，省略 = 每周都上 |
| `startDate` | 字符串 | 选填 | 学期第 1 周的周一（格式 yyyy-MM-dd）；图上只有「第 1 周 9 月 7 日」这类信息时才写 |
| `totalWeeks` | 整数 | 选填 | 学期总周数；图上明确标注时才写 |
| `periods` | 数组 | 选填 | 上课时间表：图上若列出每节的上下课时间就逐节转录（顺序与节次一致）；没有就省略整个字段 |

### weeks（周次规则）支持的写法
| 写法 | 含义 |
| --- | --- |
| （省略）或 `"all"` | 每周都上 |
| `"1-16"` | 第 1 到 16 周 |
| `"1-15单"`（或 `"1-15单周"`） | 第 1~15 周中的**单周** |
| `"2-16双"`（或 `"2-16双周"`） | 第 2~16 周中的**双周** |
| `"1,3,5,7"` | 只在这些指定周上 |
| `"1-8,10-16"` | 组合写法，取并集 |

## 转写流程（按顺序执行）
1. **读表格结构**：先看表头——每一列是一个星期几；再看行——每一行是一个节次。记下总节次数。
2. **逐列扫描**：按天（列）从上到下扫描每个课程色块，不要跳格。
3. **色块 → entries**：
   - 一个色块 = 这天的一个上课时段；
   - 色块纵向跨 n 节（连堂课）→ `periods` 写连续编号数组，如 `[1,2,3]`；
   - 同一门课在其它天 / 其它节次再次出现 → 把新 entry 追加到**同一门课**的 `entries` 里，不要新建重复课程。
4. **读色块文字**：第一行通常是课名，其余行通常是教师 / 教室，按位置对应仔细抄录。
5. **读周次标注**：色块带「单」「双」「单周」「双周」或具体周次信息 → 写入 `weeks`。
6. **处理特殊文字**：不属于课名 / 教师 / 教室的文字（如「实验」「合班」「线上」）→ 写入该课程的 `note`。
7. **最后逐门课复核**（见下方自查清单）。

## 边界情况（必须遵守）
| 情况 | 正确做法 |
| --- | --- |
| 同一门课的两个色块上下紧挨、中间有横线分开 | 视为两个独立 entry，分别写各自的 `periods`；只有**同一个完整色块**跨节才是合并 |
| 同一格里按单双周轮换两门课 | 拆成两门课程，各自填写对应 `weeks`（如 `"1-15单"`、`"2-16双"`） |
| 色块里有额外文字（「实验」「网课」「机房 404」等） | 写进该课程的 `note`；不要丢弃、不要编造 |
| 文字模糊或残缺 | 该处写「?」（如「计算机原?」），并在自查报告里列出；**不要猜测** |
| 表格只列到周五 | 照实转写存在的列即可 |
| 周六 / 周日的课 | 照常转写（day=6 / 7） |
| 图片中有时间表（08:00-08:45 等） | 按节次顺序转录进顶层 `periods`；没有就省略 |
| 图片里没有的信息 | 省略对应字段，不要写「无」或空字符串 |

## 数值与格式硬要求
- `day`：1–7 的**数字**（不要写成 `"1"`）；`periods`：≥1 的**数字**数组（不要有 `0` 或重复编号）。
- `weeks`：字符串（带引号），只允许使用上表列出的写法。
- 课程名称照抄图片：中文、英文、符号原样保留。
