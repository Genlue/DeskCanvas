# P8 批次 A 迁移探查纪要(Clock/Calendar/Progress/Batteries,2026-10-16)

> 本文是 P8 批次 A 实施前的代码事实登记,由并行探查代理产出、主代理复核。实施时直接引用,不再重新探查。

## 关键结论(影响整个 P8 的两个事实)

1. **`IWidgetSession` 生产消费者为 0**:P2 的"数字 Clock 试点"实际只覆盖了 `ClockStatusPresenter`(检查套件内的投影消费),四个批次 A 组件全部仍走 Legacy 路径;`WidgetScheduler`(Runtime)同样 0 生产消费者。P8 批次 A 是组件首次真实接入 V2 会话模型。
2. **Legacy 适配层真实存在且被全部组件使用**:`IWidgetSelfRefreshing`/`ISuspendable` 路径(适配器在宿主)是当前全部 27 个组件的运行方式;P8 的本质是把这条路径逐组件切换到 `IWidgetSession` 并删除组件侧 Legacy 消费(§17.1 兼容表的退出条件由此满足)。

## 各组件事实(要点)

### Clock
- 视图族:数字(试点目标)、模拟、翻牌、无框、字形玻璃(`FramelessGlassFrameCache` 已接 P7 账本,Owner=`clock.frame-cache:{i}`)。
- 时间源:组件内私有 DispatcherTimer,未走共享时间;`ClockStatusPresenter` 是唯一会话投影。
- 既有夹具:`ClockThemeChecks`(主题覆盖/全局材质优先级)、`ClockVisualChecks`(视觉渲染)——迁移会动到这两处断言。

### Calendar
- 日期/月历布局,私有时间刷新;时区处理为本地直取(`DateTime.Now` 族)。
- 既有夹具:`CalendarHollowChecks`(今天镂空标记,明暗双主题像素验证)——依赖当前刷新时序。

### Progress
- MetricCard 结构、设置直写(未走 draft/commit 协议)、主题回退为全局读取。

### Batteries
- 电源数据:私有 3s `DispatcherTimer` 轮询(未走 TimerService/Scheduler 租约);无共享电源 provider(P5 未覆盖)。
- 采样需求:电量变化驱动,与 ActivitySnapshot 的 PollingActive 语义对接点明确。
