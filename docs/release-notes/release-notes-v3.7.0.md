# DeskCanvas v3.7.0 更新日志

> 一个内容与连接并重的版本：新增**一言（Hitokoto）组件**——诗词 / 文学 / 动漫 / 哲学语录卡，三种排版风格、收藏与点赞、二级面板历史；**网络代理体系彻底重构**——自动 / 直连 / 系统 / 自定义四模式，主动探测系统代理、环境变量与常见本地端口（7890 / 7897 / 10809…），更新检查新增 GitHub 连通性测试与结果落盘；时钟新增**表盘-3**与**表盘颜色**系统（跟随背景 / 黑白 / 自定义明暗双色）；玻璃管线新增**闲置归还**——纯文本卡片不再长期背住整桌面捕获；全组件英文环境残留中文全面清理。主程序版本升至 3.7.0，全解决方案 22 个项目编译 0 警告 0 错误。

### 💬 1. 一言（Hitokoto）组件（全新）

* **语录卡片**：接入一言 API，诗词 / 文学 / 动漫 / 哲学等分类可筛，正文长度区间（默认 40 字内）、刷新间隔（默认 30 分钟）全部可配；离线兜底语录保底可用。
* **三种排版风格**：现代引语（左对齐 + 装饰引号水印 + 右下署名）、古典诗词（居中衬线 + 意境留白）、极简纯粹（无装饰）。
* **点赞与收藏**：卡片内点赞（同步 API 点赞数）、收藏到本地；二级面板提供历史 / 收藏 / 全部三页签与搜索，点选即切换桌面卡片；复制正文带 Toast 反馈。
* **尺寸与无边框**：预设跨度 2×1 / 2×2 / 4×2 / 4×4（默认 4×2），支持无边框模式（`IFramelessWidget.IsFrameless` 动态契约）、字体与字号定制。
* **内存与分配治理**（依据全组件内存审计 `docs/MEMORY_AUDIT_HITOKOTO.md` 逐项实施）：
  * 抓句 / 点赞三处「每次新建 `HttpClient`」改为进程级共享单例（代理设置变更才重建，请求级 6s / 5s 预算）；
  * `HitokotoStore` 索引化——`IsLiked` / `IsFavorite` 由 O(n) 线性扫描改 O(1) 集合查询（渲染热路径每次调用两次）；
  * 收藏软上限 500（载入与新增均裁剪最旧项）、历史 50 条不变；
  * 落盘改 400 ms 合并防抖——连点点赞 / 收藏不再每次全量重写 JSON；
  * 视图生命周期卫生化：订阅移到 `Loaded`、`Unloaded` 只解绑可重装载、`Dispose` 幂等且为唯一销毁路径；
  * 弹窗构造加固：`Closed` 先挂、订阅最后挂，异常时回滚注册（新增基类 `AbandonPanel`）与订阅；列表按签名增量判定，无变化不重建；
  * 设置页字体枚举改进程级 `Lazy` 缓存。

### 🌐 2. 网络代理体系重构 + 更新检查诊断

* **四模式统一**（`ProxySettings` 重写，默认改为 `auto` 自动检测）：
  * `auto`：依次探测 ① Windows 系统代理（注册表 `Internet Settings` / PAC，TCP 握手验证）→ ② 环境变量 `HTTPS_PROXY` / `HTTP_PROXY` / `ALL_PROXY` → ③ 常见本地代理端口（7890 / 7897 / 10809 等，先对照系统监听表再做快速 TCP 连接），命中即用、全部不可达落回直连；
  * `direct` 直连（绕开一切代理）· `system` 系统代理 · 自定义 URL（自动归一化补全 scheme）。
* **解析结果可追溯**：新增 `ResolvedProxy`（代理 URL / 来源 / 人类可读端点），每条网络链路（更新检查、一言、翻译、天气、地图瓦片等）共享同一解析器，行为一致。
* **更新检查诊断**：常规页新增「自动检测代理」开关与「GitHub 连通性测试」按钮——显示实际走的路由（直连 / 系统代理 / 环境变量 / 本地端口 / 自定义代理）与耗时；错误细分超时 / 代理拒绝 / DNS / TLS 重置 / 限流五类并给出成因摘要；最近一次检查结果（成功-最新 / 发现新版 / 失败原因）持久化落盘，重启后仍可见（`LastUpdateCheckStatus`）。
* **高级页代理选择器**升级为四模式（自动 / 直连 / 系统 / 自定义），自定义 URL 与模式互切不再互相覆盖。

### 🧠 4. 玻璃管线：闲置归还与多屏共享

* **闲置归还整桌面捕获**（一言审计 P1 首选落地）：`LiquidGlassWallpaper` 新增需求埋点——每次渲染 `Get()` 记录需求；空闲超过宽限期（默认 3 分钟，`DESKCANVAS_GLASS_IDLE_RELEASE_MS` 可覆盖）且无渲染进行中、未开实时采样、非全屏挂起时，自动 `Release()` 归还整桌面捕获位图（保留采样所需的缩放背景），下次渲染按需重拍。单屏可归还 8 MiB 级、4K / 多屏 30–60 MiB 级。实测：14.1 MiB 捕获 → 宽限期后归零 → 再渲染重新捕获。
* **多屏共享缩放背景**：`LiquidGlassSourceCache` 在双屏场景复用同一背板（断言 `CachedEntryCount == 1`），不再按屏重复构建。
* **无边框时钟 V2 涂层分段映射**：组件透明度 0% 零涂层 / 100% 保持基线 / 200% 完整卡片涂层——数字是窄光学表面，平铺倍数会让笔画被平灰涂层淹没，分段曲线让滑杆全程可感。
