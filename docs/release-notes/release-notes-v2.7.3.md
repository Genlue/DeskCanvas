## DeskCanvas v2.7.3 更新日志

> 重叠组件切页手势扩展（中键+滚轮、常态隐藏圆点）、翻译组件获得二级面板大窗翻译、单色黑白强调色契约修正（强调色 = 另一侧的背景色），以及该契约暴露出的"变体字典非变体读取"陷阱修复。

---

### ✨ 1. 重叠组件：中键 + 滚轮切页 & 常态隐藏圆点（1.0.1）

* **新手势**：按住鼠标中键，在组件上任意位置滚动滚轮即可在子组件间循环切换，无需对准右侧小圆点（已写入 设置 → 关于 → 快捷操作与技巧）。手势挂在窗口隧道路由并标记 Handled：内部可滚动的子组件（便签、清单等）与圆点条不会对同一次滚轮双重响应。
* **中键不再触发窗口拖动**：原先中键按下会进入窗口移动的模态循环并吞掉后续滚轮事件，切页手势无法成立。重叠组件上把中键排除出拖动触发（其他组件行为不变）；右下角缩放手柄同时改为仅左键触发（顺带修好右键在手柄上无法弹出菜单）。
* **新设置"常态隐藏切换圆点"（默认关）**：开启后圆点仅在切换动画期间或悬停组件时显示，移开后延迟 600ms 隐藏。用 Opacity 而非 IsVisible 隐藏——圆点条仍可命中，隐藏状态下"圆点处滚轮切页"照常可用，且悬停显隐保证圆点可见时一定能点。
* **兼容性**：`IStackWidget` 新增的 `AutoHideIndicators` 采用默认接口实现——旧版组件 DLL（bundle 尚未重新解压）配新宿主不再 TypeLoadException，自动回退为"总是显示"（`WidgetStackChecks` 实证：旧 DLL 在扫描阶段即抛 TypeLoad 导致组件加载失败）。

### ✨ 2. 翻译组件：二级面板大窗翻译（1.0.2）

* 控制栏新增展开按钮，打开复用 `SecondaryPanelWindow` 宿主管道的二级面板——与剪贴板/天气/提醒/笔记/大文件夹完全同款：从组件中心放大、液态玻璃材质、Esc/失焦关闭、单实例 + 重开防抖、可拖动。
* 面板内容为大窗翻译：大输入框（字数统计/清空/复制原文）、源语言/目标语言/引擎下拉（复用组件的语言与引擎表）、翻译/复制按钮、大输出区。
* **状态双向同步**：打开时带入组件当前的文本与语言引擎；面板内翻译/切换语言实时回写组件（回写后停掉组件的自动翻译防抖，避免重复请求）；关闭时把最终编辑会话交还组件，两侧始终一致。

### 🐛 3. 单色黑白：强调色 = 另一侧的背景色（契约修正）

* **契约**：单色-黑白模式下，亮色模式的强调色 = 暗色模式背景色；暗色模式的强调色 = 亮色模式背景色。
* `ThemeService` 黑白分支现在**总是**写入强调色渐变——此前无手选强调色时 `ApplyAccent` 根本不执行，黑白模式的原始 `SystemAccentColor` 键保持彩色；手选强调色也会穿透黑白模式，现被正确忽略。
* `SystemAccentColor` 基键按当前变体写入反色背景，修复无边框时钟、月历、便签、聚合卡片等**直接读取该键**的组件在黑白下仍是彩色的漏洞；无边框时钟的手选强调色解析路径加黑白守卫。
* `MonochromeBlackWhite.axaml` 的强调色族刷子（秒针/表盘中心/日历头/图标/进度环/监控环等约 20 项）从硬编码纯黑/白改回引用渐变键；**文字族保持纯黑白**。Fluent 自身的选中高亮经核实使用极性反转的 Alt 刷，黑白下自洽可读，无需覆盖。
* 新增 `AccentContrastForegroundBrush`（黑白暗色变体覆盖为黑色），修复 5 处"强调色底 + 硬编码白字"在暗色黑白下白底白字不可读：关于页手势徽章、Gallery 加号、Profiles 徽章 ×2、番茄钟活动页签、翻译/剪贴板 Toast。

### 🐛 4. 变体字典的非变体读取陷阱：日历今日圆点在暗色模式下显示暗色背景色

* **症状**：单色-黑白 + 暗色模式下，日历"今日"圆点呈黑灰色而非亮色背景色，且改动"暗色模式背景色"设置它会同步变化。
* **根因（实证）**：无变体 `TryFindResource(key)` 重载按 `ThemeVariant.Default` 匹配 ThemeDictionaries，**永远命中亮色（Default）字典**——挂在暗色窗口上的同一控件，无变体解析得 `#112233`（暗背景）、带变体解析得 `#FEDCBA`（亮背景）。圆点拿到的是亮色字典里的 `SystemAccentColorDark1`（黑白下 = 暗色背景色），其 Color 是活的 DynamicResource，因此跟随背景色设置变化。强调色渐变映射本身无误，错在读取方式。
* **修复**：Month 今日圆点、Aggregate 今日圆点、AnalogWorldSingle 表盘刻度（顺带修复暗色下刻度取到黑色的既有问题）、Widget/StackView 彩色模式描边，共 5 处改为**变体显式解析**（沿用 `MarkdownRenderer.ResolveThemed` 的既有先例）。
* **回归检查**：新增 `MonochromeAccentChecks` 检查项目（渐变映射契约 / 手选色被黑白忽略 / 强调色变体不受黑白影响 / 组件式变体查找契约），并把无变体查找的陷阱结果作为 INFO 记录在案。
