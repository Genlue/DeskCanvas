## uWidgetsPlus v2.1.0 更新日志

> 桌面小组件回归"桌面家具"本位：所有小组件强制置底（普通窗口永远盖住组件），天气预报等待办二级面板只浮在组件层之上、仍位于普通窗口之下；同时修复打开二级面板卡死（三重对抗循环），液态玻璃 2.0 折射梯度处处连续化、消除四角硬接缝。

---

### 🧩 1. 小组件 z 序带序机制（WidgetZOrder / Widget）

* 新增窗口 z 序带序服务：普通应用窗口（顶层）＞ 二级面板（中层）＞ 桌面小组件（底层，仅高于桌面）。任何激活 / Alt-Tab / 拖动结束 / ShowWindow 引起的 z 序变化，都在 `WM_WINDOWPOSCHANGED` 之后幂等修正回本带——修正合并派发（Send 优先级在下一帧渲染前完成），窗口不会可见地跳上跳下；
* 组件窗口在 `Opened` 即钉扎到底部带：点击、激活、拖动、全屏挂起恢复都不再浮到普通窗口之上；便签 / 搜索等输入组件照常接收键盘（窗口激活与 z 序提升是两回事）；
* 带内判定是幂等谓词"下方无可见的非组件窗口"——多个组件的修正自然收敛，互不打架；
* 新增 12 项带序运行时检查（BottomBandChecks，离屏窗口、不干扰桌面），覆盖置底、面板锚定、激活吸收、重挂恢复与回退。

### 🪟 2. 二级面板仅置于其上 + 卡死修复（WeatherPopup / RemindersPopup / BigFolderPopup / ClipboardPopup）

* 四个二级面板（天气详情、待办清单、大文件夹、剪贴板）显示时锚定到组件带顶端：高于所有组件、低于普通窗口，点击面板自身也不会窜到最顶。面板通常比组件大，锚定取"最顶组件"而非仅其宿主，避免滑进邻格组件下面；
* **修复打开二级面板卡死（三重对抗循环）**：
  * 面板 XAML 的 `Topmost="True"` 与带序钩子互相拉锯（Avalonia 属性同步把面板推回顶层 ↔ 钩子拉回普通层），UI 线程无限自旋——面板统一降级 Topmost，交给带序机制管理；
  * `Show(owner)` 产生的 native owned 关系把底钉组件与面板在 z 序上耦合：系统为维持"owned 永远在 owner 之上"反复重排整个 owned 组，两组钩子互相触发——切断组件与面板的原生 owner 链接（Avalonia 会把所有 `ShowInTaskbar=false` 窗口挂到同一个隐藏离屏窗口下），并以 `WS_EX_TOOLWINDOW` 保持任务栏 / Alt-Tab 行为不变；
  * 系统内部的 owned 组维护移动携带 `SWP_NOZORDER`，旧钩子见标志即跳过，组件被挪出带后永不修正——改为无视标志、每次放置后按实际 z 链判带；
  * 面板锚点解析跳过面板自身与不可见窗口，杜绝 `SetWindowPos(P, P)` 未定义行为与乱停位置；顶层带窗口（任务栏、置顶工具）不作锚点，避免面板被拖进顶层带。

### 💧 3. 液态玻璃 2.0 折射梯度处处连续（LiquidGlassV2Effect / LiquidGlassV2Renderer）

* 原版库的圆角矩形 SDF 梯度沿卡片对角线硬切换轴向、并在弧心线上塌缩成 45° 尖峰；当折射带宽超过约 1.2× 圆角半径（出厂光学在小圆角卡片上即是如此）时，四个角会切出径向硬接缝；
* 重构为处处连续：角域保留径向扇形、边缘带保持精确边缘法线、深内部将径向沿对角线镜像以平滑衔接扇形；SkSL 着色器与 CPU 参考实现同步重构，光学检查程序纳入 V2 材质校验。

---

**说明**：小组件之间的相对次序刻意放任（都保证在普通窗口之下即可）——强制每个组件压到绝对底部只会与桌面窗口层制造无意义的抖动。置底后液态玻璃的实时折射采样始终读到壁纸本体，视觉反而更正确。
