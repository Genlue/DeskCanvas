## uWidgetsPlus v1.9.19 更新日志

> 本次更新带来全新重构的液态玻璃材质：完整移植 Kyant0/AndroidLiquidGlass 2.0 的光学模型（圆角矩形 SDF 折射透镜 + 深度效果 + 对角色散 + 发丝描边高光），出厂参数对齐作者调校配方；原「液态玻璃」更名为「柔光玻璃」，新材质正式定名「液态玻璃」。

---

### 💧 1. 全新液态玻璃材质（LiquidGlassV2）
* **光学模型**：移植 AndroidLiquidGlass 2.0-alpha03——内部完全透传，折射局限于边缘窄带（宽度 = 峰值位移的一半），位移沿 `1 - sqrt(1 - x²)` 四分之一圆在轮廓处达峰并向内采样（背景在厚玻璃边缘被放大）；SDF 梯度按膨胀半径（1.5×圆角）计算并混入径向分量（depthEffect，玻璃厚度感）；
* **色彩**：iOS vibrancy 饱和提升（默认 ≈×1.5）取代去饱和；轻微背景模糊；表面中性层；可选七档对角色散；
* **边缘高光**：修正为库的绘制层配方——描边实际宽度 = ceil(0.5dp)×2、整体模糊 0.25dp、裁剪到轮廓内，加色（Plus）混合纯白，左上 / 右下对角受光（iOS 双亮边），falloff 对齐库默认；
* **出厂参数**：模糊 50 / 折射 100 / 边缘高光 50 / 活力 33 / 色散 30 / 实时采样 10ms / 背景清晰度 40%，与作者当前调校一致；
* **设置**：模糊 / 折射 / 色散 / 边缘高光 / 活力 五根滑杆 + 实时采样与背景清晰度，光学区标题随材质切换。

### 🌫️ 2. 材质更名
* 新材质（LiquidGlassV2）定名「**液态玻璃**」；旧「液态玻璃」透镜材质更名为「**柔光玻璃**」，其柔光晕 / 光谱弥散 / 染色扩散配方保持不变；
* 新增材质调度器（LiquidGlassDispatch）：弹出面板（待办 / 天气 / 剪贴板 / 大文件夹）、Map 适配、无边框时钟、软件渲染回退与 CPU 弹窗预渲染均按材质自动路由。

### 🛠️ 3. 其他
* 壁纸校准对话框按材质读写对齐偏移；
* WiX 安装器版本号与 AssemblyInfo 同步（v1.9.19）。
