## DeskCanvas v2.7.4 更新日志

> 单色模式新增第三种风格"背景色"（黑白契约随之收敛为严格无彩色）、设置窗口右侧内容区改版（macOS 风格不透明内容板 + 浮动操作按钮）、组件自适应尺寸治本（宿主内容驱动最小窗口尺寸，翻译组件展开按钮截断修复）。

---

### ✨ 1. 单色模式新增"背景色"风格，黑白强调色契约收敛为严格无彩色

* **新风格"背景色"**：全部文字与强调色锁定为另一侧的背景色——亮色模式渲染暗色背景色、暗色模式渲染亮色背景色（历史上"黑白"的原始行为，独立成档）。新增 `MonochromeBackground.axaml` 主题字典（文字族与强调色族共用同色，装饰性描边/表盘保持无彩色）。
* **黑白契约修正**：黑白的强调色不再是"反色背景色"，而是**严格无彩色**——亮色模式纯黑、暗色模式纯白，强调色跟随元素（聚合卡城市名、电量圆环、主题色板等）不再染上背景色；原"强调色 = 反色背景"行为移交"背景色"档。
* `ThemeService` 单色分支重写为三路 switch：黑白/背景色都**总是**覆写强调色渐变（手选强调色在两种模式下均被忽略，命令式读取 `SystemAccentColor` 的组件保持契约）。
* 组件侧适配：电量圆环/低电量徽章按三档变体解析（强调色档恢复尊重手选色）、无边框时钟强调色守卫从黑白扩展到全部无强调色档、月历今日圆点改用变体显式解析读取（避免非变体查找命中亮色字典的既有陷阱）、聚合卡今日数字改用 `AccentContrastForegroundBrush` 对比刷。
* `MonochromeAccentChecks` 扩展新契约的回归检查。

### ✨ 2. 组件自适应尺寸治本：任意像素尺寸不再截断/重叠

* **宿主内容驱动最小窗口尺寸**：自由模式下组件窗口此前最小可到 48px，内容里任何固定宽行（控件栏、按钮组）放不下就被卡片裁掉或与同级元素重叠。现在宿主在内容每轮布局后读取其 `DesiredSize`——被压缩的布局会把放不下的自然尺寸报进 DesiredSize（>可用即溢出信号）——据此抬高窗口 Min 尺寸：缩放手柄、自定义尺寸对话框、拖拽全部被钳在"内容能存活"的下限；已小于下限的旧布局自动长到位。视图自身的自适应收缩（隐藏次要控件）会让 DesiredSize 跟着变小，所以下限始终是"视图已尽力之后仍需要的"尺寸。手动网格模式、锁定尺寸、无边框组件、档位过渡动画均不干预。
* **翻译组件控件栏测量驱动降级**（修复展开按钮被截断）：控件栏 7 列中 6 列固定 Auto，窗口一窄最后几列直接被裁。改为按档位计算自然宽度、选出能放下的最小档位一次应用：藏引擎 → 藏交换 → 藏立即翻译 → 藏展开（二级面板唯一入口，最后才让位）。对 locale 文案长度、字体缩放、DPI 一概成立——彻底替代旧的 `width >= 135` 单阈值。截图场景（160px 小窗）实测：引擎收起，`自动 ⇄ 中文 ⧉` 完整放下，展开按钮完好。
* **防振荡细节**：对活树调用 `Measure(infinity)` 会覆写 DesiredSize 触发布局无限乒乓；`IsVisible=false` 的控件 DesiredSize 清零，会让"恢复它会多宽"的计算失真而在两档间打转。最终实现全部纯读取 + 可见时宽度缓存，每轮布局最多应用一次档位。
* 字数统计/状态文本补省略号裁剪（`TextTrimming`），极窄时不再挤压重叠。
* 新增 `WidgetAdaptiveChecks` 检查项目：最小尺寸数学、七档宽度下"控件栏放得下 + DesiredSize 不溢出 + 可见性单调降级"契约、160px 截图场景展开按钮存活。

### ✨ 3. 设置窗口内容区改版（macOS 27 风格）

* 右侧内容区从整窗玻璃改为**不透明纯色内容板**（亮色纯白 / 暗色 #1C1C1E 抬升灰），侧栏保持玻璃——左缝细线分隔、左上左下圆角封口，窗口圆角裁切外缘。
* 刷新/关闭按钮改为**浮动圆形卡片**：玻璃底 + 投影 + 悬停/按下过渡（`ClipToBounds=False` 防止 Avalonia 11.1 把投影裁成方形）。
* 单色风格选择器更新为三选一（黑白 / 背景色 / 强调色），新增对应文案资源；主题色板按钮在全部单色档下读取 ThemeService 写入的强调色渐变。

### 🐛 4. 组件右键菜单圆角 8 → 4

* 右键菜单固定 4px 圆角（外壳与菜单项悬停高亮同圆度），与 Fluent 子菜单浮层（OverlayCornerRadius）一致，不再跟随组件卡片圆角。
