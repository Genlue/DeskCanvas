## DeskCanvas v3.1.0 更新日志

> 一个围绕**无边框时钟液态玻璃 V2**的版本：数字光学按 V2 材质彻底重写（不再复用旧柔光玻璃的配方），新增"液态玻璃透明度"滑块，修复桌面时钟把缓存键画进数字、滑块拖了没反应、亚克力材质残留三处缺陷；顺带根治单色模式下文本选区与强调色按钮的白上白、设置窗口短窗体的导航滚动穿透。主程序升到 3.1.0，Clock 组件升到 1.3.0，`ClockThemeChecks` 新增 V2 光学/键值泄漏/可感性三组断言，编译 0 警告 0 错误。

---

### 💎 1. 无边框时钟：V2 数字光学重写（`GlyphLiquidGlassRenderer`）

* **问题**：V2 材质的数字一直复用旧"柔光玻璃"的配方路径——边缘染色取自 bloom 场、高光带强烈染色、meniscus 光带照搬卡片模型，而 V2 的四个滑杆（模糊/折射/高光/色散）里只有部分真正作用到数字上；旧材质残留的参数（EdgeWidth/EdgeTint/LightAngle）还会污染 V2 输出。
* **修复**：新增 `ResolveGlyphOptics`，把 V2 自己的滑杆投影进"笔画尺度"的透镜模型，旧参数一律锁死为固定值；染色源改为对**未折射背景**单独低通采样的"环境场"，细碎彩色背景不再把描边染成彩色断点；高光带换成 sheen + 吸收模型（亮环境需要吸收而不只是反射），反射峰值上限从 0.78 压到 0.32，细笔画保得住背景；染色、高光染色、直接边缘染色在 V2 下全部降饱和降强度，仅保留 V2 滑杆的响应。
* **顺带修复**：V2 位图改以 `Unpremul` 语义安装（`SKColor` 存直通 RGB），否则 Skia 对抗锯齿覆盖率二次预乘，轮廓出现亮边；旧柔光材质保持原 `Premul` 表示不变。

### 🎚 2. 新增"液态玻璃透明度"滑块（仅 V2）

* `FramelessClockModel` 新增 `LiquidGlassOpacity`（0–200%，默认 100% = 现有效果），经 `Frame.GlyphOpacity` 透传到渲染端控制数字涂层强度；旧材质渲染结果与它完全无关（有逐字节断言）。
* 设置界面新增滑块行，仅当全局主题是液态玻璃 V2 时显示（监听 `IAppSettingsProvider.DataChanged` 动态显隐）；帧缓存键附带当前透明度，拖动即 miss 全部缓存、立刻按新值重渲染。
* **发布前修复的两处缺陷**（发布说明里如实记录）：
  * **桌面时钟把缓存键画进数字**——预渲染管线把缓存键直接传给字形布局器，历史上"键 = 时间文本"恰好成立，键加上后缀后 `|glassOpacity:100` 就被当成 16 个字符排上桌面。修复后只有裸时间文本进字形布局，后缀只留在缓存簿记里（回归断言：重建时间掩码，掩码外必须零墨水像素）。
  * **滑块拖了没反应**——原线性映射 0.22×档位，常见设置下 100% 档涂层混合仅约 4%、200% 也才约 8%，肉眼不可感。改为分段映射：0% 无涂层、100% 保持 V2 基准、200% 达到完整卡片涂层（与旧材质同主题不透明度下的实心度一致；回归断言：200% 与 100% 的全图平均差必须 > 8/255）。

### 🪟 3. 修复：亚克力材质切换残留

* **问题**：从毛玻璃切回液态玻璃后，部分窗口上亚克力背景残留不清。根因：原实现靠"先设 `None` 再设目标"强迫 Win32 重应用，但无重定位位图的窗口上 `None` 并不真正清除合成画笔（报告为 Transparent 却短路），后续 `Transparent` 提示也就不再生效。
* **修复**：`ApplyWindowTransparency` 直接赋目标级别，不再绕道 `None`；两轮重试逻辑相应简化。`ClockThemeChecks` 新增原生往返探针——反射驱动真实窗口在亚克力↔液态玻璃间往返两次，探测 WinUI 合成层 `_blurEffect` 字段验证画笔真正清除。

### 🖌 4. 单色强调色跟随：文本选区与强调色按钮

* `App.axaml` 全局 `TextBox` 样式补 `SelectionBrush`（`SystemControlHighlightAccentBrush`）与 `SelectionForegroundBrush`（`AccentContrastForegroundBrush`），选区颜色跟随强调色极性，黑白/背景色档下不再白上白。
* `Profiles` 页"新建/切换"强调色按钮新增 `AccentButtonForeground/Background` 系列资源覆写（悬停 0.85、按下 0.7 透明度，disabled 保留 Fluent 灰），单色三档下前景/背景保持对比。`MonochromeAccentChecks` 改用 `StubSettings` + `ProbeApp` 跳过宿主启动与用户配置，对真实模板化按钮做六变体×四状态断言。

### 🧭 5. 修复：设置窗口导航滚动穿透

* 短窗体下导航列表可以滚到浮动标题条（AppTitle/红绿灯）底下。`Settings.axaml` 把滚动视口整体下移并 `ClipToBounds`，标题条移出滚动区域——导航再怎么滚也不会从标题条底下穿过。

### 🧪 6. 测试与版本

* `ClockThemeChecks`：新增 V2 数字光学断言组（透明度三档输出、旧材质无视该设置、V2 无视旧参数污染、折射归零无位移、模糊/鲜艳度/色散各自响应、高光向内衰减、四档覆盖率直通 RGB 无亮边、低覆盖率合成不增亮）+ 材质实例多轮往返 + 原生透明度往返探针 + 键值泄漏与滑块可感性回归。
* 版本号：主程序 3.1.0（AssemblyInfo + Package.wxs 同步），Clock 1.3.0。
