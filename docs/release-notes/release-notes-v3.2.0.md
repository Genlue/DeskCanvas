# DeskCanvas v3.2.0 更新日志

> 一个围绕**组件库**的版本：库内右键组件直接按预设尺寸放进桌面（每一档都带真实比例的实时迷你预览），逐组件登记了预设尺寸并删除、改名了三个组件，卡片去掉描述小字；上版发布后遗留的「新添加组件锁死毛玻璃」修复一并入库。主程序升到 3.2.0，Clock 组件升到 1.4.0，`WidgetInfoAttribute` 新增可选 `presetSpans` 契约并保留旧签名兼容构造函数，编译 0 警告 0 错误。

---

### 📐 1. 组件库右键尺寸面板

* 组件库内右键多尺寸组件，弹出上下文菜单（与应用其余菜单同一套样式与行为）列出该组件的全部预设尺寸；每一项都是**该尺寸的实时迷你预览**（按 100 DIP/格渲染、缩放进对应宽高比，外框上限 256×128、目标每格 64 DIP）加尺寸徽章，点击即以该尺寸直接放入桌面（沿用空位扫描落位）。
* 单尺寸组件不设右键；卡片提示文案区分「点击添加到桌面」与「左键添加到桌面 · 右键选择尺寸」。菜单关闭时释放预览控件，与页面卡片同一 Dispose 契约，不留常驻实例。

### 🧩 2. 逐组件预设尺寸登记（`presetSpans`）

* `WidgetInfoAttribute` 新增可选 `presetSpans` 参数（`"2x2,4x2,4x4"` 格式），预设跨度作为组件自身知识写在插件注册特性里，宿主不硬编码插件类型；解析时跳过非法项并拒绝 0 跨度。
* 18 个组件带右键尺寸面板：标准三档 `2×2 / 4×2 / 4×4`（月份、预报、多仪表盘、清单、文件展示框、大文件夹、音乐、剪贴板、翻译、地图、画框相册、番茄钟、时间进度、电池与外设、组件重叠），以及特殊档——数字时钟 `2×1 / 4×2`、笔记 `2×2 / 4×4`、单文件 `1×1 / 2×2`、搜索 `4×1 / 2×2 / 4×2 / 4×4`。
* 默认值调整：**搜索**左键直接放 4×2（与库内展示一致）；**数字时钟**默认 2×2→4×2（原默认不在其预设档内，取与预览卡一致的横版）。其余组件默认不变。

### 🗑 3. 组件增删与改名

* 删除「样式 2（AnalogII）」与「世界时钟（World）」两个组件：视图、模型、设置页与 AnalogWorldSingle 控件一并移除，重叠组件的子组件预设清单同步去掉样式 2（已确认现有桌面布局无这两者的放置，`WidgetFactory` 对无法激活的条目仍有跳过保护）。
* 改名（中英资源同步）：样式 1 → **表盘-1**，样式 3 → **表盘-2**，文件夹 → **文件展示框**。
* 组件库卡片去除右下角的描述小字，标题 + 尺寸徽章更聚焦。

### 🔒 4. 插件契约向后兼容

* 主构造函数新增第 8 个参数后，旧组件 DLL 的自定义特性 blob 绑定的仍是 7 参数构造函数——缺了它会整装配集反射激活失败（热更新新旧版本错配时全部组件消失）。补回 7 参数委托构造函数，旧 DLL 与新宿主混跑不受影响（`SettingsProbe` 回归从 0 个预览恢复到 32 个）。

### 🪟 5. 修复：新添加的无边框时钟锁死在毛玻璃

* **问题**：刚从组件库添加（或 `layout.json` 条目尚无 `Settings`）的组件，工厂以 `model == null` 激活；构造函数以模型为**第一个**参数的组件（无边框时钟、地图、时间进度等）会回退到不带设置提供者的短构造函数——组件从此收不到 `DataChanged`，无论全局主题是什么都渲染回退材质（无边框时钟表现为永远毛玻璃）。
* **修复**：`WidgetFactory.CreateWidgetControl` 在模型缺失时构造该组件模型的默认实例（`TryCreateDefaultModel`，模型无法默认构造时保持旧行为），完整构造函数可达后由 `ActivatorUtilities` 从 DI 填入 `IAppSettingsProvider`——新添加的组件与从存储布局恢复的组件接线完全一致。`ClockThemeChecks` 新增 Part 1b 断言组钉住该契约。
* **同源修复**：`FramelessClockSettings` 的 `appSettingsProvider` 参数去掉缺省值——带缺省值时 `ActivatorUtilities` 用缺省 (null) 而不解析已注册服务，编辑窗口视图模型永远无提供者，其主题相关行（液态玻璃透明度）不随全局主题显隐。
