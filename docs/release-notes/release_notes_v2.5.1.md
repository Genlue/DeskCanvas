## uWidgetsPlus v2.5.1 更新日志

> 全局文字阴影上线;无边框时钟的液态玻璃边缘与字重设置彻底重做;二级面板唤出时的任务栏闪现与组件保存被静默丢弃一并根治。
>
> 说明:2.5.0 未单独发版,本版合并了 2.5.0 与 2.5.1 的全部改动。

---

### ✨ 1. 全局文字阴影(新功能,默认关闭)

* 新增 **设置 → 外观 → 全局文字阴影**:开启后,桌面组件窗口内的文字统一带上一层柔和投影,在花哨壁纸 / 亮色照片上也能看清;强度 0-100 连续可调,模糊、偏移、不透明度一起缩放,手感是一个「淡 → 浓」的单一旋钮。
* 作用域严格限定为**桌面组件窗口内**的文字:设置窗口、各类对话框、二级面板、托盘菜单保持系统原生清晰文字,不受影响。
* 与主题联动:换主题、换壁纸自动主题、开关深浅色都会即时重算阴影。

### 🐛 2. 全局文字阴影:清单条目等「可编辑文字」此前拿不到阴影

* **此前**:阴影只加在 `TextBlock` 上,而待办清单的每一条是**可编辑文本框**(`ClickThroughTextBox`),它的文字由 `TextPresenter` 绘制——于是出现"清单标题和计数有阴影、下面一条条待办却没有"的割裂观感。
* **现在**:两类文字宿主统一覆盖,可编辑标签(清单条目、各类可编辑名称)与普通文字观感一致。
* 顺带修复:**拖动强度滑块时右侧数值框不跟手**——之前滑块改了值、数值框收不到通知,一直停在旧数字。

### 🐛 3. 唤出二级面板时任务栏「闪一下 uWidgetsPlus」根治

* **此前**:组件与二级面板为了保持在正确的层级带里,必须切断窗口的原生 owner 链;而 Avalonia 每次重算窗口样式都会按它缓存的 `ShowInTaskbar` 把 `WS_EX_APPWINDOW` 位写回来(该位优先级**高于**工具窗口位),并把无 owner 的窗口重新挂回它的屏幕外隐藏窗口——于是资源管理器在中间态里给窗口建了一次任务栏按钮又销毁,表现为一闪而过。开的次数越多越稳定出现。
* **现在**:样式重算后立即用 `SWP_FRAMECHANGED` 刷新(可见窗口的扩展样式有缓存,不刷新就可能被按旧值判定)、样式回调里同时**清掉 APPWINDOW**、窗口每次被放置(显示 / 激活 / 状态变化 / 透明级别切换)都复核一次工具窗口位与 owner 链,任何一条被改回去都会自愈。
* 现已把这条写进自动化检查:带内窗口**永远不会**处于"资源管理器会给按钮"的状态(可见 + 非工具窗口 + 无 owner 或带 APPWINDOW),hide/show、透明级别、装饰变更、激活等所有重算路径逐项断言。

### 🐛 4. 组件设置被静默丢弃 / 拖动位置回跳

* **此前**:组件窗口持有的布局写入器以「屏幕 ID」定位自己的配置条目,插拔坞站、改显示器排列后该 ID 失效,于是**保存被静默丢弃**:相册加文件夹不落盘、拖动位置记不住、激活后位置回跳。
* **现在**:改为遍历全部屏幕配置按**屏幕身份**(硬件 ID + 匿名屏防误配)查找命中项,并顺手把失效的 `ScreenId` 自愈重绑;仍然只更新既有条目、绝不新增(保留"组件不会自己复活"的保护)。
* 同时修复拖动结束后位置偶尔不落盘:原生移动循环会吞掉鼠标抬起事件,现在移动回调之后排队一次确定性提交。

### ✨ 5. 无边框时钟:液态玻璃「毛刺边 / 断断续续」根治

* **根因**:数字笔画的玻璃光学全部由一个「距离场」驱动(透镜位移、亮边线、边缘染色、方向性高光),旧实现用 3×3 棋盘扫描近似距离,把距离量化成 1 或 √2 —— 更糟的是**量化误差随边缘走向变化**(水平边约 1 px、45° 斜边约 1.414 px)。亮边线只有约 1.5 px 宽,于是斜边上的亮线被逐像素调制成虚线,看起来就是毛刺、断断续续。
* **现在**:换成**精确欧氏距离变换**(线性时间、无方向误差)+ **抗锯齿覆盖率亚像素修正**(字体光栅器本来就告诉了我们轮廓落在像素内的哪里)。
* 实测(对已知解析形状采样):近场轮廓误差 **0.399 px → 0.145 px(−64%)**,抗锯齿边界像素误差 **0.032 px**;真实字形轮廓的"断裂率"在 4×2 / 2×2 / 4×1 尺寸下分别从 1.57% / 0.90% / 1.46% 降到 1.01% / 0.38% / 0.75%。

### ✨ 6. 无边框时钟:字体粗细换成连续滑轨,并且真的有效

* **此前**:九档下拉看着专业,实际对精选字体完全无效——**华为锁屏超窄体只有一个 Black 字面、Impact 只有一个 Regular**,九档全部落到同一张字面;默认字体的最重字面是 Bold,最高的两档同样是死的。
* **现在**:改成**无数值连续拖动条**(最左细、最右粗),并把粗细定义为"位置"而非固定的字号档位:参考字重及以下仍由字体的**真实字面**渲染(观感与历史逐像素一致),参考字重以上按位置**合成加粗**。
* 结果:700 → 900 这一段对**每一种**字体都会变粗(单字面字体也能粗到超出它自身字面的程度),细端保持该字体能达到的最细;实测单字面字体 700 → 900 墨迹面积 55.7% → 62.5%,默认字体 100 → 700 → 900 为 19.0% → 41.4% → 67.3%。

### 🔧 7. 内部整理

* 无边框时钟的材质应用收敛为**单一入口**:窗口加载、全局主题变更、深浅色切换、模型刷新、全屏挂起 / 恢复全部走同一条路径,根除"某一处漏掉一步导致时钟不跟随全局主题"的复发。
* 托盘 / 全屏挂起 / 睡眠恢复相关行为不变。
