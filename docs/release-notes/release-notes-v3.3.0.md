# DeskCanvas v3.3.0 更新日志

> 一个围绕**无边框时钟**的版本：时钟材质锁定在毛玻璃，主题分支机器（材质解析器、字形玻璃渲染器、预渲染帧缓存）连同其余三种材质的样式与代码一并删除，净删约 2200 行；更新弹窗去掉外围多余毛玻璃圈并取消强制置顶。主程序升到 3.3.0，Clock 组件升到 1.5.0，编译 0 警告 0 错误。

---

### 🕒 1. 无边框时钟锁定毛玻璃

* **行为**：数字永远以洗色 + 高光描边渲染在**操作系统原生亚克力背板**上（扫描线窗口区域把模糊限制在字形内），不再跟随全局表面主题——全局主题是液态玻璃、新液态玻璃还是纯色，时钟外观一律不变。全局主题仍提供毛玻璃观感自身用到的输入：深浅色变体洗色、跟随强调色的强调色、全局字体家族。
* **删除**：`FramelessThemeResolver`（材质解析器）、`GlyphLiquidGlassRenderer`（字形玻璃光学渲染器，954 行）、`FramelessGlassFrameCache`（48 MB 预渲染帧缓存）三个服务整文件移除；主视图从 1046 行重写至约 470 行，只保留毛玻璃一个渲染分支，失效入口收敛为单一的 `InvalidateGlyphs()`，亚克力背板仅在窗口加载时断言一次。壁纸采样联动、窗口移动重采样、挂起期缓存释放等仅服务于渲染管线的逻辑随之删除（`IWidgetSuspendable` 实现摘除，其余组件不受影响）。
* **观感不变**：毛玻璃态的洗色透明度、遮罩、高光描边逐像素保持原样；高光描边染色强度钉在出厂默认值，不再读取全局液态玻璃的边缘染色参数（切断跨材质耦合）。组件库预览与新添加路径渲染同一外观。
* **设置收敛**：删除「液态玻璃透明度」滑杆（V2 专属涂层强度，随渲染管线失去意义），设置页不再读取任何全局材质/光学状态，编辑窗口构造函数随之精简。

### 🧹 2. 模型与契约清理

* `FramelessClockModel` 删除 `LiquidGlassOpacity`（与已删的 `ThemeMode` / `DyeIntensity` / `RefractionWidth` 同列），旧 `layout.json` 中的残留值反序列化时直接忽略，不致命。
* 宿主 `LiquidGlassRenderer.Frame` 删除 `GlyphOpacity` 参数——唯一读取方是已删除的字形渲染器，桌面卡片玻璃管线不受影响。
* 组件副标题改为「纯净数字自适应网格拉伸，毛玻璃效果直达数字轮廓」（中英资源同步）；《项目解构报告》Clock 段落与检查工程表同步（顺带修正其中遗留的「6 视图 / 世界时钟 / ClockGlassChecks」过时描述）。

### 🪟 3. 修复：更新弹窗

* **外围毛玻璃圈**：窗口整体开亚克力而内容面板内缩 8px，环带露出整窗模糊形成一圈多余毛玻璃——面板改为全出血（`Margin="0"` + `ClipToBounds`，与编辑窗口同一模式），面板自身玻璃质感不受影响。
* **取消强制置顶**：删除 `Topmost="True"`，更新弹窗变为普通层级窗口。

### 🧪 4. 验证与版本

* `scripts/check-structure.ps1` 通过（17 个插件工程、宿主/Core 边界与插件契约齐全）。
