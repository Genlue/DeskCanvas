## uWidgetsPlus v2.0.0 更新日志

> 稳定性大版本：彻底排查并修复「液态玻璃」组件瞬间闪成纯色空白、设置窗口整窗透明只剩红绿灯两大顽疾，并修复右键打开设置必然崩溃的回归。

---

### 🛠 1. 液态玻璃组件纯色闪烁：多级防御（LiquidGlassWallpaper / DesktopCapturer）

* **根因定位**：Windows MPO（多平面叠加）将壁纸置于硬件合成层，`PrintWindow` 抓取物理上无法读取叠加层内容——叠加层升降切换的瞬间，采样拿到的是桌面底色或「大部分纯色 + 少量残影」的混合帧；混合帧骗过均匀性校验被发布到玻璃卡片，即「组件瞬间变成一块纯色空白」；
* **快速路径逐帧校验**：16×9 粗网格采样（<1ms），纯色 / 纯黑帧不再被信任；
* **时间域校验**：真实壁纸内容不可能在相邻两轮间让 85% 以上采样点同时突变，此类帧（MPO 切换、引擎重启瞬间）一律判为坏帧；
* **坏帧掩蔽**：坏帧轮次一律沿用上一帧实时画面（250ms 宽限），宽限后自愈重解析——真正的壁纸更换与引擎重启仍在一轮内正常放行；长时叠加层切换期间冻结在正确画面，不再退到错误的静态壁纸文件；
* **引用计数竞态修复**：`Get()` 的 `AddRef` 移入锁内，消除坏帧释放与取用之间的冲突窗口（潜在垃圾帧 / 原生崩溃来源）。

### 🪟 2. 设置窗口全透明只剩红绿灯：不透明兜底 + 自愈（Settings）

* **根因**：设置窗口为零背板设计（`Background="Transparent"` + 80% 半透明 tint），DWM 亚克力背板被重置（屏幕共享、锁屏、显示器变更、驱动重置）时窗口近乎不可见，唯一硬编码色红绿灯依然醒目；
* **不透明兜底**：监听实际 `TransparencyLevel`，跌出 `AcrylicBlur` 即切换为全不透明背景，恢复后自动回到毛玻璃态；
* **背板自愈**：2 秒健康检查发现新鲜掉落时强制重建背板并写入诊断日志；
* **提示赋值幂等**：不再于每次设置保存时拆装实时窗口的合成背板；
* **修复打开设置必崩回归**：XAML 填充期 `WindowSurface` 尚未创建即触发透明度回调导致的 `NullReferenceException`。

### ⏱ 3. 无边框时钟渲染竞态（FramelessDigital）

* 实时采样每轮清空字形缓存并取消在途渲染，首帧在 10ms 采样节拍下竞速失败、长时间停留在纯色字形块；改为在途渲染完成后补一次渲染，前瞻缓存不再被逐轮烧毁；
* 逐帧 `TransparencyLevelHint` 重赋值改为幂等缓存数组，消除逐轮 Win32 窗口属性重戳。

---

**说明**：`PrintWindow` 无法读取 MPO 硬件叠加层是系统级限制，本版以多级坏帧防御保证卡片不再闪烁纯色；彻底根治（改用 Windows.Graphics.Capture 直接读取合成内容）已列入后续计划。
