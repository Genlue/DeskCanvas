## uWidgetsPlus v2.3.0 更新日志

> 二级面板全面进化:统一开合动画基类 + 锚点式弹出——面板从触发组件「长」出来、收回时「缩」回组件,圆角全程与组件对齐;配合一轮全组件内存 / CPU 隐患治理。

---

### ✨ 1. 二级面板统一开合动画基类(SecondaryPanelWindow)

* 天气详情 / 待办清单 / 大文件夹 / 剪贴板四个二级面板的弹出、收回行为统一收敛到共享基类 `SecondaryPanelWindow`:出生位置居中于触发组件(钳制在屏幕工作区内)、Material 3 emphasized 缓动曲线、单实例 + 250ms 重开冷却,Esc / 失焦 / 重触发三种关闭路径合并为一次动画收场。

### ✨ 2. 弹出动画重构:锚点式缩放——从组件本身展开 / 收回

* **此前**:面板以「中心缩放 0.94→1 + 上浮 14px + 淡入」出现,动画与触发组件毫无关联,观感生硬。
* **现在**:面板以**触发组件的中心为变换原点**,从 60% 尺寸缩放展开 + 淡入(320ms emphasized decelerate);关闭时沿同一原点缩回 60% 并淡出(180ms emphasized accelerate)——面板像是从组件本身「长」出来,收回时「缩」回组件里。
* 原点按面板最终落点与组件中心实时换算(含 DPI 与工作区钳制偏移):组件贴近屏幕边缘、面板被钳制偏移时,面板会朝组件所在方向展开;原点计算全程容错,任何异常回退为中心缩放,绝不会让面板停在不可见状态。

### ✨ 3. 面板圆角跟随组件圆角(全链路一致)

* **此前**面板圆角硬编码(天气 20、其余 18),与设置中的组件圆角(全局 + 每屏覆盖 + 小尺寸自适应缩放)对不上,桌面上两种弧度。
* 现在打开面板时把宿主组件的实际视觉圆角(`Widget.Radius`)传入:面板卡片、实时液态玻璃采样(`LiquidGlassSurface`)、预渲染玻璃位图、大文件夹原生模糊的 `SetWindowRgn` 窗口区域**全部使用同一圆角**。
* 玻璃预渲染缓存键纳入圆角:调整圆角设置后立即重渲染,不会命中旧圆角的陈旧缓存。
* 顺手修复:大文件夹在原生模糊主题(窗口区域裁剪)下面板残留 AXAML 静态 0.95 缩放、永久缩小 5% 的问题。

### 🧠 4. 全组件内存 / CPU 隐患治理

* **挂起链路补全**(全屏检测 → `SuspendAll`):挂起时清空玻璃源缓存 `GlassSourceCache`、禁用按需抓屏、壁纸事件重武装、内存 Trim 移出 UI 线程——全屏挂起不再残留实时采样开销。
* **Picture / Music / Batteries 组件接入 `IWidgetSuspendable`**,挂起时释放图片解码缓存、媒体会话轮询与电池刷新。
* **Stack 重叠组件与番茄钟的无界泄漏修复**(事件订阅 / 定时器随窗口生命周期释放)。
* **相册(Gallery)预览**:设置窗口内的实时预览不再反复重置剪贴板监视器,并清理历史预览实例。
* **地图瓦片磁盘缓存 512MB 上限**(此前无界增长);**时钟毛玻璃主题**每秒刷新复用 LOH 缓冲;**进度组件**点阵 tooltip 防抖。
