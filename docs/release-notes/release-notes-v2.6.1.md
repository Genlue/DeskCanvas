## uWidgetsPlus v2.6.1 更新日志

> 红绿灯失焦颜色、全局滚动条形态、新增组件的放置与遮挡、清单/笔记的一级界面交互、组件设置窗口置底——这一轮把桌面小组件日常使用的最后几处别扭全部捋直。

---

### 🐛 1. 设置窗口红绿灯:亮色模式失焦时不再发黑

* **根因**:Avalonia 样式按定义顺序生效(后者覆盖前者,没有 CSS 优先级),`unfocused` 兜底样式(深灰)写在了 `.light` 变体之后,把亮色模式的浅灰盖成了深灰。
* **现在**:兜底样式移到主题变体之前。亮色失焦恢复 macOS 灰(底色 `#DFDFDF`、描边 `#C4C4C4`),暗色失焦不变。

### 🎨 2. 全局滚动条:圆端长条,横向滚动条根除

* Fluent 未展开的滑块原本是 16px × 0.125 = **2px 的细长方形**;现在收起缩放提到 0.25(**4px**,比未展开稍粗一档),滑块全圆角呈**圆端长条**(药丸)。
* 悬停展开态(16px)同样是圆端; Fluent 的展开 / 自动隐藏机制原封不动,这一个定义被设置页、所有组件、弹窗、菜单的滚动条自动引用。
* **横向滚动条在组件卡片里结构性不可能出现**:悬停样式对横向一律 `Hidden`(可滚动、永不显示滚动条)——清单名等不换行文本再长也不会冒出横向条,同时保住搜索 / 天气的横向滚轮与文本框光标跟随。

### ✨ 3. 新增组件直接落到桌面第一个空闲格

* **此前**:从组件库点击新增时,组件被放在点击位置(即设置窗口正下方),而组件又被强制置底——必须先拖走窗口才能拖到新组件。
* **现在**:点击后直接放到桌面**第一个未被占据的网格**(从左到右、从上到下扫描,整跨度能放下才算命中);全部排满则回到**左上角无视占用**盖上。连点两下不再重合,删除组件后的空位会被自动回填。
* 放置判定改读**实时布局**(此前读的是显示器轮询快照,最长滞后 1.5 秒,这正是连点重合与"删了不回填"的根因)。非 2×2 组件同样按各自跨度检索。

### ✨ 4. 清单组件:卡片默认只读,编辑收进二级面板

* **现在**:卡片上默认**只保留打勾和打开二级面板**;清单名与条目文本不再响应双击编辑(单击 / 双击都是拖动卡片)。
* 组件设置新增「**在组件卡片上直接编辑清单名与条目**」,打开后恢复旧的双击就地编辑,翻转即时生效。
* 横向滚动条在清单卡片里彻底移除(溢出内容裁剪显示)。

### ✨ 5. 笔记组件:新增二级面板,双击编辑默认关闭

* 笔记卡片头部新增**展开按钮**,打开全新二级面板:
  * 内部文本来源——标题 + 正文全尺寸编辑,失焦 / 关闭即保存;
  * 单文件来源——正文直接编辑写回 Markdown 文件;
  * 文件夹来源——只读渲染预览(提示去磁盘编辑原文件)。
* **双击卡片编辑内容默认关闭**,可在组件设置里打开;关闭状态下双击卡片直接打开二级面板。

### 🐛 6. 组件设置窗口不再被置底

* **根因**:组件设置以置底的组件窗口为 owner 模态打开,而 Windows 规则是 owned 窗口永远在 owner 之上——于是它被钉在"组件带之上、所有普通窗口之下"。
* **现在**:改为独立打开,遵守**普通窗口逻辑**(正常 z 序、有任务栏按钮、不会被压在其他窗口下面)。

### 🧪 7. 新增 RemindersCardChecks 真值检查

* 用 Avalonia.Headless 走真实样式系统,断言清单卡片"默认关 / 设置开 / 运行时翻转"三场景下全部文本框的编辑开关状态。
* 顺带记录两个样式系统的坑:覆写 `StyleKeyOverride` 的控件按**样式键**参与类型选择器匹配(写实际类型永远匹配不到);样式按定义顺序生效,没有 CSS 优先级。
