# 快捷指令动作改善实施计划

按以下顺序实施；路径相对 `src/Widgets/Shortcuts/`。依据 2026-10-19 当前工作区，包含尚未提交的 v2 图编辑器。

现有 `ShortcutsGraphChecks` 49 项、`ShortcutsSmoke` 均通过。额外无系统副作用探针复现了下述取值、循环、取消及导入问题，需补入正式回归。

## 1. P0：修正执行逻辑

修改 `Services/ShortcutRunner.cs`、`Executors/RunShortcutExecutor.cs`，新增 `Services/WorkflowValidator.cs`：

- **空结果沿用旧 last**：`SetOutput` 在结果为空字符串时也更新 last；无数据输出的动作不更新。界面将“上一步结果”改为“最近的数据结果”，并显示具体来源。
- **连线与引用行为不同**：统一 `Resolve`；节点引用、数据连线直接返回原始值，仅显式模板展开占位符，禁止对来源结果二次展开。
- **缺失来源静默变空串**：区分未执行、Null、空文本、参数未提供。仅未提供参数时应用默认值；数字非法、必填缺失、来源未执行时定位到节点和参数，不再静默 fallback。
- **嵌套循环覆盖 index/item**：增加循环 frame，进入时压栈，退出时恢复外层变量；每轮隔离临时输出，禁止读取上轮未更新的节点结果。跨轮累积使用显式变量或收集节点。
- **循环后继重复执行**：循环体解释器增加 done 后继边界，到达边界先返回所属循环。校验器定位 body 接入 done 后续路径的连线；循环体尾部不接线表示结束本轮，无需画回边。
- **非法控制流被当作成功**：循环外 break/continue 报错；while 达到上限且条件仍成立时报 `IterationLimitExceeded`。禁止普通执行回边，保留现有深度、步数守卫。
- **父流程停止，子流程继续**：`RunAsync` 接收外部取消令牌，父子运行关联取消，共享根运行的步数和截止时间预算。超时取消底层操作并等待清理，不能只用 `WaitAsync` 放弃等待；取消向上传递 Cancelled。
- **运行中编辑影响执行**：启动时克隆图快照，增加 RunId 和父子调用关系，事件与结果按 RunId 归属。
- **确认规则因入口不同而变化**：将快捷指令级、组件级确认汇入统一运行入口，接通卡片、弹窗、编辑器、热键和子流程调用；确认只做一次。无窗口或对话框异常明确失败，删除当前自动放行逻辑。

## 2. P0/P1：统一动作输入输出与连线规则

修改 `Models/ActionCatalog.cs`、`WorkflowGraph.cs`、`ShortcutsDocument.cs`、`Services/Executors/ActionExecutors.cs`：

- `ParamSpec` 增加数据类型、Required、AllowEmpty、Bindable、说明、条件显隐；`ParamKind` 仅决定编辑控件。先支持 Text、Number、Boolean、DateTime、路径、List、Object、Null。
- 动作定义增加明确的执行端口和 `OutputSpec[]`，声明端口 ID、名称、类型、说明、默认输出；取消所有普通动作统一提供 value 的兜底。
- 执行器返回 `ActionResult { Outputs, Summary, Error }`：Outputs 保存机器数据，Summary 保存本地化反馈。等待、通知、按键、锁屏等只提供执行出口，不返回“已完成”作为数据。
- `RunContext.Outputs` 改为节点 ID + 端口 ID → 类型化值；引用增加 SourcePort，连线实际读取 FromPort。立即修复 `setVar` 已存结果却没有 value 出口、导入拒绝其数据线的问题。
- 参数只保留一个生效来源：手动值、节点端口、命名变量或模板。连线与“使用变量”写同一种绑定，画布数据线由绑定投影，禁止暗中覆盖仍可编辑的字面量。
- `WorkflowValidator` 共用到连线、导入、载入诊断和运行前：检查唯一入口、ID、端点、参数、类型、有限数字、范围和重复来源。执行线只能接 in，数据线只能接可绑定参数；当前执行线接参数圆点也会被接受，必须拦截。
- 全部动作由执行线调度，数据线只传值；断开的动作显示“未接入执行流”，被引用但不保证先执行时报错。仅数据线、没有有效执行路径的图不能显示成功。
- 命名变量与节点输出分开命名空间；循环提供只在 body 有效的 index/item 端口，保留名禁止被覆盖。类型不匹配时拒绝连接或要求转换节点，不将对象、列表静默转字符串。
- 分支比较增加显式类型、大小写选项、>=、<=、布尔判断，数值失败不退化成字典序。switch 改为可增删 case 行及稳定 case ID，端口显示匹配值，移除固定四路和 `|` 拼接。

## 3. P1：修正现有动作的含义

| 动作 | 具体修改 |
| --- | --- |
| httpRequest | 增加 headers、query、contentType 及 PUT/PATCH/DELETE；输出 body、statusCode、headers。空响应保留空串，非 2xx 保留响应数据并走错误策略；现有 20,000 字符上限改为明确超限错误或 truncated 标记，按响应 charset 解码。 |
| screenshot | 增加屏幕范围、保存目录；输出实际 FilePath。文件名加毫秒或唯一后缀，避免连续截图覆盖。 |
| openApp/openFile/openFolder/openUrl/webSearch/openDataFolder | 输出实际目标路径或最终 URL，取消文件名、查询词和本地化成功句等不一致返回；明确成功仅表示启动请求已提交，补齐各类目标校验。 |
| textTransform | replace 时才显示查找/替换；find 为空、operation 非法时报错；大小写规则可选，输出 Text。 |
| getClipboard/setClipboard | 明确读写文本；读取返回 text 与 hasText，写入允许空串清空。 |
| randomNumber/currentDate/wait | 随机数输出 Number，明确整数闭区间，min > max 报错；日期输出 DateTime，格式化独立；等待明确单位及小数秒，不输出状态文字。 |
| setVolume/muteToggle | 输出实际 level:Number / muted:Boolean；解除静音改为明确选项，新增 setMute(Boolean)，避免音量动作隐式改变静音状态。 |
| sendKeys/sendHotkey | 将 sendKeys 拆为 typeText、sendKeySequence；单组合键保留 sendHotkey。共用校验、录制保护、取消及 finally 松键；显示前台目标，后续支持绑定窗口。 |
| themeDarkMode/themeSurface/widgetsVisibility | 输出稳定枚举或 Boolean；深色 toggle 使用深浅双态，三态操作命名为 cycle；确定性设置使用明确值。 |
| addReminder/notify/note | 提醒增加到期时间，复用或扩展宿主领域服务，避免直接维护另一份提醒 JSON；通知负责显示消息；note 仅作画布注释，不计执行进度。旧 comment 按迁移规则处理。 |

在 runner 中增加“停止 / 转错误出口”策略，默认停止；错误对象含稳定 code、message、nodeId，取消不走错误恢复。仅对显式启用的 HTTP 等动作提供重试，避免重复副作用。

同步修改 `ShortcutTemplates.cs`：静音模板使用 setMute(true)，专注模板明确播放意图及无媒体处理，截图提示引用实际文件路径。

## 4. P1/P2：补齐基础节点

每项同步增加契约、执行器、参数编辑、本地化和规范；数据节点同样通过执行线运行。

| 优先级 | 节点 | 输入 → 输出及规则 |
| --- | --- | --- |
| P1 | text / number / boolean | 常量 → 对应类型 value，补独立数据来源。 |
| P1 | getVar / calculate / convertValue | 变量名 → 原类型值；两数及四则运算 → Number；值及目标类型 → 转换结果。除零、转换失败明确报错。 |
| P1 | splitText / joinText | 文本及分隔符 → List；List 及分隔符 → Text；明确 trim 和保留空项选项。 |
| P1 | createList / listCount / listItem / collect | 多项 → List；List → 长度；List + 从 0 开始的下标 → 元素；循环体值 → 当前循环收集列表，在 done 后读取。 |
| P1 | parseJson / getProperty / toJson | 文本 → Object/List；对象及字段路径 → 原类型值；对象 → JSON 文本。字段缺失与 JSON null 分开处理。 |
| P1 | mergeValue | 互斥分支结果 → 当前路径已产生的值；不得先求值未执行分支，无结果或多个结果时报错。执行流合并继续使用现有多入线。 |
| P1 | askInput / showResult | 标题、默认值、输入类型 → value；任意值 → 可复制的文本/列表/对象视图。输入取消终止运行；复用宿主输入对话框和公共控件。 |
| P1 | 流程输入 / return | 快捷指令声明输入字段，start 暴露输入端口，return 返回类型化值；runShortcut 按稳定目标 ID 映射参数并返回结果，替换当前只返回“已运行”的实现。卡片、热键按字段弹出输入表单。 |
| P1 | selectFile / selectFolder / pathExists / readTextFile / writeTextFile | 选择 → 路径；路径 → Boolean/文本；路径 + 文本 + 覆盖/追加模式 → 写入路径。写入默认拒绝覆盖，明确编码和大小限制。 |
| P2 | listFiles / pathJoin / pathInfo | 目录及过滤 → 路径 List；路径片段 → 路径；路径 → 名称、扩展名、父目录。 |
| P2 | formatDate / dateAdd / dateDiff | 日期、格式/时区或偏移 → Text/DateTime/时长。 |
| P2 | findWindow / activateWindow / waitForWindow | 窗口条件 → 窗口引用；引用 → 激活；条件及超时 → 窗口引用。通过宿主 Windows 适配层实现，供键盘动作绑定。 |

扩展 `tests/ShortcutsGraphChecks`、`tests/ShortcutsSmoke`，接入 `scripts/verify.ps1`：

- **数据**：setVar 出口可连；引用/连线一致；空值、默认值、非法数字；模板不二次展开；未执行分支和上一轮残留不可误读。
- **执行**：仅数据线不假成功；执行线不能接参数口；动态 switch、分支汇合；循环后继恰好一次；嵌套序号恢复；循环外 break/continue 报错；while 上限失败。
- **生命周期**：取消父流程后子流程后续节点执行次数为零；超时取消底层操作；运行快照不受编辑影响；各入口确认一致；子流程输入/返回和根预算有效。
