# P3 第二批公共控件迁移验收报告(2026-10-16)

本批按执行计划推进 P3 剩余公共控件,由当前代理(GLM-5.3)直接实施并执行统一验证。保留任务开始时的全部未提交改动;未执行任何提交、重置或清理类 Git 操作。本报告仅验收下列切片,不代表长期方案中 P3 全部完成。

## 切片内容:Setting、SettingLayoutPanel、ColorInput 迁入共享 UI

- `DeskCanvas.UI.Controls` 新增真实 Avalonia `Setting`(行模板 + `SettingLayoutPanel` 三槽自适应布局引擎与滞回带)、`ColorInput`(ColorPicker + Hex 草稿 + 内联校验提交状态机)及配套枚举;UI 项目新增中央版本管理的 `Avalonia.Controls.ColorPicker` 11.1.3 包引用,依赖边界守卫不变。
- **文案注入而非复制**:共享模板不再引用宿主 Locale;`AdminRequiredText`/`RestartRequiredText`/`InvalidFormatText` 为注入属性(英文中性默认),宿主兼容外观构造时写入 Locale 值。全部现有页面与组件零改动保持原渲染;共享 AXAML 无 CJK 字面量,R7 口径不变。
- 宿主 `Views/Controls` 保留三个兼容外观类型(继承共享实现):Setting(旧字段别名 + legacy shape getters + 文案注入)、SettingLayoutPanel(`Slot` 附加属性别名,旧 AXAML 解析路径不变)、ColorInput(旧 `ColorInputValueCommittedEventArgs`/`ValueCommitted` 签名转发);`Setting.axaml`/`ColorInput.axaml` 改为空 legacy 声明,旧 URI 继续可加载。
- `SharedComponentCatalog` 扩展至滑块 ×4 + Setting 行 ×2 + ColorInput ×2;Samples README 更新 `ui:` namespace、文案策略与旧外观契约。
- `UiFoundationChecks` 的 W3 自适应布局段与两批设置页检查改用共享类型别名;`RedundancyGuardChecks` 兼容断言在兼容外观模式下继续成立,无需放宽。

## 决策记录

- 面板壳(`SecondaryPanelShell`)**本批不迁移**:它依赖宿主 `LiquidGlassSurface`(玻璃渲染与 `LiquidGlassDispatch` 平台路径)、`PanelDragBehavior`、`PanelAppearance` 模型与 `PanelAppearanceResolver`,并被九个二级弹窗与 `SecondaryPanelWindow` 深度集成。迁移需先定义玻璃表面端口与拖动行为归属,列为独立后续切片;强行抽取会在没有第二个玻璃消费者验证的情况下制造第二套表面语义,违反执行纪律第 2 条。
- 宿主命名空间不再声明 `SettingLayoutMode`/`SettingEffectiveLayout`/`SettingLayoutSlot` 与 ColorInput 枚举:全仓库 C# 消费者仅宿主自身与检查程序,已改用共享类型;AXAML 枚举字面量经属性类型转换继续可用。旧包二进制的 AXAML 按类型+属性名解析,不直接引用枚举类型 Token,加载路径不变(旧包实机装载验证仍属未完成项)。
- 布局引擎(Measure/Arrange)、颜色状态机与提交语义逐行保持原实现,仅移动归属;`UiSharedAvaloniaChecks` 新增断言钉住行为等价。
