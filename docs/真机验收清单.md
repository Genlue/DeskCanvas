# 真机验收清单(累积,主代理维护)

> 依据铁律 3:真机验收(多屏/IME/GPU/旧包二进制/SMTC/磁盘/性能)未完成的项必须持续明确标记,不得以无头检查宣称通过。本清单逐项给出**可人工执行的步骤**;每项完成后在"结果"列填写日期与观察,未执行的项保持"等待人工执行"。
>
> 来源:P3–P5 接线验收报告、P3 第二批/第三批迁移报告、P4–P5 第四批迁移报告、ADR-P3b/P4b/P5b、UI-Foundation 验收清单。新切片产生新的真机项时追加到对应分区。

## 使用方法

按分区执行;每个分区内的步骤在该分区一次真机会话中可顺带完成。执行环境记录:机器 CPU/GPU、内存、Windows 版本、显示器拓扑、DPI、刷新率、构建版本(HEAD 33be6f8 + 未提交改动)。
