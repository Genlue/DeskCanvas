本批按执行计划推进 P6 的两个切片(owner 面板服务化、窗口角色与平台能力边界),由两个并行实施子代理分别实施、主代理集成修复与统一验证。保留任务开始时的全部未提交改动;未执行任何提交、重置或清理类 Git 操作。本报告仅验收本批切片。

## 切片 1:owner 面板服务化(PanelService)

- `SecondaryPanelWindow` 的 `static Dictionary<Type,…> ActivePanels/LastCloseTimes`(按 CLR 类型的进程级单例)迁入 `PanelService`:身份键 = `"process|PanelKey"`(进程单例)或 `"owner:{InstanceId}|PanelKey"`(每 owner,InstanceId 为空回退窗口哈希);toggle/冷却按身份键判定,语义与旧实现逐位等价。
- `PanelService.Open(PanelRequest)`:冷却拒绝→同身份动画 toggle→工厂创建+重绑身份+`ShowAsSecondaryPanel(owner)`;工厂/Show 失败无残留、不启动冷却(水位线幽灵清理 + Abandon 语义)。
- **owner 生命周期契约(新增)**:PerOwner 打开订阅 owner 窗口 Closed;`WidgetFactory.CloseScreen/CloseAll` 关闭组件前 `PanelService.CloseForOwner(widget.InstanceId)`——组件关闭/移除时归属面板不再残留。
- `CloseForDisplayChange` 语义原样迁入,公共入口保留。
- 13 个未迁移弹窗经 legacy 类型键转发,行为逐位不变。
- **两个差异消费者**:Weather=PerOwner(两个天气组件各自拥有面板,不再互相顶替);Dice=ProcessSingleton 显式声明(删除私有 activeInstance,修复裸 Show 缺陷)。Wheel/Fortune 同步修复裸 Show→`ShowAsSecondaryPanel`(最小改动,P8 再迁服务)。
- 集成期修复(主代理):`PanelService.Open` 的 Show 失败路径由 `UnregisterPanel`(会记冷却)改为 `AbandonPanel`(不记,与其注释契约一致);`PanelService` 补 `using DeskCanvas.Views`;`WindowRoles` 的 `ConditionalWeakTable` 值类型枚举改装箱;四个对话框文件补 `using DeskCanvas.Services`;`tests/UiFoundationChecks/PanelShellChecks` 三处反射断言从已删除的 `ActivePanels` 迁移到 `PanelService.activePanels`(legacy 键强断言);`tests/WidgetReleaseChecks` 静态注册表信息行同步;`PanelOwnershipChecks` 补 `LegacyProbePanel.Abandon` 包装、`WindowRoleChecks` 的 `ResetForChecks` 改反射调用。
