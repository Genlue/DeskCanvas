## 维护规则

1. 新增兼容措施必须先在本表登记(措施 / 入口 / 夹具 / 退出条件),再落代码。
2. 每个切片收尾时复查"当前状态"列:退出条件已满足的条目应在该切片内移除对应措施并更新本表与 `docs/架构重构执行计划.md`。
3. `ApiSnapshotChecks` 基线(`tests/ApiSnapshotChecks/Baseline.txt`)是 #5、#7、#8 的机器可读边界:diff 非空即发布门禁失败,须显式重录并说明理由。
4. 真机项(旧包装载矩阵、旧 DLL 基线回归)不在自动门禁内,发货前对照 `docs/真机验收清单.md` 执行;`scripts/release-gate.ps1` 尾部会提示。
